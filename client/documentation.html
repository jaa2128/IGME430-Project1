Books API Documentation

/getBookTitles Documentation

Supported Methods:

GET HEAD

Query Params:

language (optional) - A language to filter by

genre (optional) - A genre to filter by (partial matching supported i.e Fiction -> Historical Fiction, Classical Fiction, etc.)

Returns:

A JSON array of book name strings.
Format: [string]

Examples:

Request: /getBookTitles

Result: ["title1", "title2", "title3"]

Request: /getBookTitles?language=title1and3language

Result: ["title1", "title3"]

/getBooks Documentation

Supported Methods:

GET HEAD

Query Params:

country (optional) - A country of origin to filter by.

language (optional) - A language to filter by.

genre (optional) - A genre to filter by (partial matching supported i.e Fiction -> Historical Fiction, Classical Fiction, etc.).

Returns:

A JSON array of book objects.
Format: [{author: string, country: string, language: string, link?: string, pages: number, title: string, year: number, genres?: [string], rating?: number}]

Examples:

Request: /getBooks?language=Icelandic

Result: author: "Halldor Laxness", country: "Iceland", language: "Icelandic", link: "https://en.wikipedia.org/wiki/Independent_People\n", pages: 470, title: "Independent People", year: 1934

/getBook Documentation

Supported Methods:

GET HEAD

Query Params:

title - The title of the book.

Returns:

A JSON book object.
Format: {author: string, country: string, language: string, link?: string, pages: number, title: string, year: number, genres?: [string], rating?: number}

Examples:

Request: /getBook?title=Independent People

Result: author: "Halldor Laxness", country: "Iceland", language: "Icelandic", link: "https://en.wikipedia.org/wiki/Independent_People\n", pages: 470, title: "Independent People", year: 1934

Request: /getBook

Result: 400 Error

/getAllBooks Documentation

Supported Methods:

GET HEAD

Query Params:

No supported parameters

Returns:

A JSON array of book objects.
Format: [{author: string, country: string, language: string, link?: string, pages: number, title: string, year: number, genres?: [string], rating?: number}]

Examples:

Request: /getAllBooks

Result: [{"author": "Chinua Achebe", "country": "Nigeria", "language": "English", "link": "https://en.wikipedia.org/wiki/Things_Fall_Apart\n", "pages": 209, "title": "Things Fall Apart", "year": 1958,"genres": ["Historical Fiction", "Postcolonial Literature"]}, ...]

/addBook Documentation

Supported Methods:

POST

Supported Body Formats:

application/json application/x-www-form-urlencoded

Body Params:

author Type: string - The book's author

country Type: string - The book's country of origin

language Type: string - The book's language

pages Type: number - The book's number of pages

title Type: string - The book's title

year Type: number - The book's publication year

genres Type: string - A comma separated string of the book's genres

Returns:

A JSON book object representing the new or updated book
Format: [{author: string, country: string, language: string, link: string, pages: number, title: string, year: number, genres?: [string], rating?: number}]

Examples:

Request: /addBook

Body: {author: 'Author1', country: 'United States', language: 'English', pages: '200', title: 'Title1', year: 2001, genres: 'genre1,genre2' } author

Result: {"author": "Author1", "country": "United States", "language": "English", "pages": 200, "title": "Title1", "year": 2001, "genres": ["genre1", "genre2"]}

Request: /addBook

Body: {author: 'Author1', language: 'English'} author

Result: 400 Error (Missing Params)

/rateBook Documentation

Supported Methods:

POST

Supported Body Formats:

application/json application/x-www-form-urlencoded

Body Params:

title Type: string - The book's title

rating Type: number - The rating of the book

Returns:

A JSON book object representing the updated book, or a 404 if no book exists with that title
Format: {author: string, country: string, language: string, link?: string, pages: number, title: string, year: number, genres?: [string], rating: number}

Examples:

Request: /rateBook

Body: {title: 'Title1', rating: 3}

Result: {"author": "Author1", "country": "United States", "language": "English", "pages": 200, "title": "Title1", "year": 2001, "genres": ["genre1", "genre2"], rating: 3}

Request: /rateBook

Body: {title: 'Title1'}

Result: 400 Error (Missing Params)

Request: /rateBook

Body: {title: 'FakeBook', rating: 5}

Result: 404 Error (No Book to Rate)
